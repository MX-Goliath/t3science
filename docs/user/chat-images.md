# Images in chat

Agents can show images directly in a conversation. T3 Code renders standard Markdown image syntax,
including public `https://` URLs and image files inside the current project workspace:

```md
![Preview](https://example.com/preview.png)
![Local result](./artifacts/result.png)
```

Local images are served by the connected environment, so they also remain visible when the client
is connected remotely. Selecting an image opens a larger view. Images generated by Codex appear in
the conversation automatically after generation completes.
